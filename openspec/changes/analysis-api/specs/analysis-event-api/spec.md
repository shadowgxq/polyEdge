## ADDED Requirements

### Requirement: 默认事件列表接口（热门 / 世界杯两分类）

系统 SHALL 提供默认事件列表接口，按 `hot`（Polymarket 热门）与 `world_cup`（世界杯筛选子集）两个分类返回事件卡片。每个卡片 MUST 含事件名、各选项赔率（隐含概率）、**事件级概览偏差标签**（取事件内 `|bias_i|` 最大选项的三分类标签并标注该选项名）、该数据的快照时间；返回条数受配置的每页上限约束，超出上限不在首屏无限堆叠。世界杯分类无匹配事件时返回明确空列表标识供前端空态。来源：PRD §4.1/AC-1、bias-algorithm §4/§5、data-source §3。

#### Scenario: 按分类返回默认列表

- **WHEN** 客户端请求默认列表并指定分类为 `hot` 或 `world_cup`
- **THEN** 系统由缓存读取该分类默认事件、逐事件计算各选项偏差，返回事件卡片列表（含选项/赔率/概览偏差标签/快照时间），条数不超过配置上限

#### Scenario: 卡片概览标签取 |bias| 最大选项

- **WHEN** 装配某事件卡片且该事件适用偏差分析
- **THEN** 卡片偏差标签取该事件内 `|bias_i|` 最大选项的三分类标签，并同时标注该选项名

#### Scenario: 事件不适用偏差时卡片标注

- **WHEN** 某事件仅 1 个有效选项或 `Σ price = 0`（不适用偏差分析）
- **THEN** 卡片标注「不适用偏差分析」而非产出偏差标签，仅展示原始选项数据

#### Scenario: 世界杯分类无匹配事件

- **WHEN** 请求 `world_cup` 分类且无匹配事件
- **THEN** 返回明确的空列表标识供前端展示空态，不返回错误

### Requirement: 单事件偏差明细接口

系统 SHALL 提供按 slug 的单事件明细接口，返回该事件每个可分析选项的赔率（隐含概率）、热度、偏差评分、三分类标签，以及降级标注（全事件退化为纯交易热度、选项被排除、事件不适用偏差分析）；并返回事件级 `commentCount`（不参与单选项偏差）与数据快照时间。来源：PRD §4.3/§5.2、bias-algorithm §3.5/§4/§6、data-source §4。

#### Scenario: 返回每个可分析选项的分析结果

- **WHEN** 客户端按 slug 请求单事件明细且事件适用偏差分析
- **THEN** 对每个可分析选项返回赔率、热度、偏差评分、三分类标签，并附事件级 `commentCount` 与数据快照时间

#### Scenario: 全事件退化为纯交易热度时标注

- **WHEN** 事件内任一选项缺 per-option 参与数据触发全事件退化
- **THEN** 明细结果标注「纯交易热度」降级态，选项偏差按退化口径计算后返回

#### Scenario: 无效选项排除标注

- **WHEN** 某选项价格全为 0 或数据缺失被排除出偏差计算
- **THEN** 该选项在结果中被标注为已排除，其余有效选项的偏差在剩余有效集上重归一后返回

#### Scenario: 事件不适用偏差分析

- **WHEN** 事件仅 1 个有效选项或 `Σ price = 0`
- **THEN** 返回「不适用偏差分析」标注与原始选项数据，不产出偏差评分

### Requirement: 事件输入 slug 解析接口

系统 SHALL 提供事件输入解析接口：接收 Polymarket 事件链接或 slug，由后端提取 slug、判定有效性并按 slug 拉取事件；解析不出有效事件时返回明确空态供前端引导重试，MUST NOT 静默失败。来源：PRD §4.2/AC-2、data-source §3。

#### Scenario: 从链接解析 slug 并返回事件

- **WHEN** 客户端提交一个合法 Polymarket 事件链接或 slug
- **THEN** 后端提取 slug、按 slug 拉取并返回该事件明细结果

#### Scenario: 解析不出有效事件

- **WHEN** 提交的链接/slug 无法解析到有效 Polymarket 事件
- **THEN** 返回明确的「未找到」空态供前端引导重试，不返回空的成功数据

### Requirement: 事件名称搜索接口（含本地模糊回退）

系统 SHALL 提供事件名称搜索接口：优先走 Polymarket 搜索返回候选事件；当搜索能力不可用时 MUST 退化为在已缓存事件集内本地模糊匹配，并在响应中标注搜索范围（`upstream` / `local_cache`）供前端提示「仅在当前收录事件范围内搜索」；搜不到时返回空候选列表并带范围标注，不静默失败。来源：PRD §4.2/AC-2、data-source §3。

#### Scenario: 上游搜索可用返回候选

- **WHEN** 客户端以事件名称查询且 Polymarket 搜索可用
- **THEN** 返回候选事件列表并标注搜索范围为 `upstream`

#### Scenario: 上游搜索不可用本地模糊回退

- **WHEN** Polymarket 搜索能力不可用
- **THEN** 在已缓存事件集内本地模糊匹配返回候选，并标注搜索范围为 `local_cache`

#### Scenario: 搜不到返回空候选带范围

- **WHEN** 查询在当前搜索范围内无匹配
- **THEN** 返回空候选列表并带上搜索范围标注，供前端展示空态，不返回错误
