## ADDED Requirements

### Requirement: 多事件排行三榜聚合接口

系统 SHALL 提供多事件排行接口，对**当前 Tab 默认列表**（`hot` 或 `world_cup` 分类）内所有事件的所有选项各自计算 `bias_i`（仍在其所属事件内归一），并聚合为三榜：泡沫风险榜（`bias_i ≥ +T`，按 `bias_i` 降序）、冷门机会榜（`bias_i ≤ −T`，按 `bias_i` 升序）、合理列表（`|bias_i| < T`）。三榜与三分类阈值 `T` 对齐且互斥无交集，每个选项恰落入且仅落入一榜。来源：PRD §4.4/AC-4、bias-algorithm §5。

#### Scenario: 对当前 Tab 默认列表聚合三榜

- **WHEN** 客户端请求排行并指定分类 `hot` 或 `world_cup`
- **THEN** 系统对该分类默认列表所有事件的所有选项算 `bias_i`，聚合出泡沫风险榜、冷门机会榜、合理列表三榜

#### Scenario: 三榜互斥无交集

- **WHEN** 对聚合的所有选项分档
- **THEN** 每个选项按其 `bias_i` 相对 `±T` 的位置恰落入泡沫榜 / 冷门榜 / 合理列表之一，三者无交集、无遗漏

#### Scenario: 泡沫榜降序、冷门榜升序

- **WHEN** 生成泡沫风险榜与冷门机会榜
- **THEN** 泡沫风险榜按 `bias_i` 降序、冷门机会榜按 `bias_i` 升序排列

### Requirement: 榜单项事件归属与 TopN 截取

系统 SHALL 使每条榜单项保留其事件归属（事件 slug/标题、选项名、赔率、偏差评分、三分类标签）以便前端回跳单事件明细；每榜按配置的 TopN 截取，超出部分不返回。某榜无入榜项时 MUST 返回空数组，其余两榜正常返回，不整体报错。来源：PRD §4.4/AC-4/§5.2、bias-algorithm §5。

#### Scenario: 榜单项含事件归属可回跳

- **WHEN** 装配任一榜单项
- **THEN** 该项包含所属事件 slug/标题、选项名、赔率、偏差评分与三分类标签，供前端回跳对应单事件明细

#### Scenario: 按配置 TopN 截取

- **WHEN** 某榜入榜项数超过配置的 TopN
- **THEN** 该榜按排序取前 TopN 项返回，其余不返回

#### Scenario: 某榜为空不影响其余榜

- **WHEN** 某一榜无任何入榜选项
- **THEN** 该榜返回空数组、其余两榜正常返回，接口不整体报错
