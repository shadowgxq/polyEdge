# 数据来源与口径映射

> 本文档说明本产品用到的 Polymarket 数据及其**产品口径映射**，供 [PRD.md](./PRD.md) 与 [bias-algorithm.md](./bias-algorithm.md) 引用。这里是**产品级数据口径**，不是接口契约；具体 endpoint、参数、字段名与错误码由后续 OpenSpec 规格与技术方案确定。

## 1. 数据源

| 数据源 | 用途 |
| --- | --- |
| Polymarket Gamma API | 事件、市场（选项）、成交量、流动性、24h 成交量、评论数等元数据。 |
| Polymarket CLOB API | 选项当前价格/赔率（隐含概率），下单簿深度（若需要）。 |

- **唯一数据源为 Polymarket**，本期不接任何第三方（无 X / Twitter、无 Google Trends、无独立体育赔率源）。
- 世界杯事件不是独立数据源，而是 Polymarket 事件的**筛选子集**（按体育/足球/World Cup 标签或关键词过滤）。

## 2. 产品口径映射

| 产品概念 | Polymarket 侧来源（指示性） | 粒度 | 用途 |
| --- | --- | --- | --- |
| 事件名 | 事件 title / slug | 事件级 | 展示、手动输入解析 |
| 选项名 | market / outcome 名称 | 选项级 | 展示 |
| 赔率/隐含概率 | 选项价格（CLOB / outcomePrices） | 选项级 | 概率份额 `p_i` |
| 成交量 | volume | 选项级 | 交易热度 |
| 流动性 | liquidity | 选项级 | 交易热度 |
| 24h 成交量 | volume24hr | 选项级 | 交易热度 |
| 换手率（派生） | volume24hr / volume | 选项级 | 交易热度（近端加速度） |
| 订单簿深度（可选） | CLOB 买卖盘总深度 | 选项级 | 交易热度（可选信号，MVP 默认不启用） |
| 持仓/交易者人数 | holders / traders（若可得） | 选项级 | 社交热度 |
| 事件评论数 | commentCount | **事件级** | 事件级关注度标签（不参与单选项偏差） |

> 字段名为指示性，以实际 API 返回为准，字段映射与缺失兜底在技术方案中固化。

## 3. 数据获取方式

- **默认事件列表**：按热门规则（成交量/流动性等）拉取一批事件；世界杯 Tab 额外按筛选条件过滤。
- **手动输入**：
  - 链接 → 解析出事件 slug → 按 slug 拉取事件。
  - 名称 → 走 Polymarket 搜索 → 返回候选事件供用户选择。
- **分享图片代理**：分享海报出图时，Polymarket 的图片资源经后端同源代理转发，解决前端 canvas 跨域污染；仅转发公开静态资源，不改变数据口径。

## 4. 缓存与时效

| 项 | 口径 |
| --- | --- |
| 缓存位置 | 后端（Redis 可用） |
| 缓存对象 | 事件/选项原始数据与算好的偏差结果 |
| 拉取策略 | 默认列表（热门 + 世界杯）由后端定时任务预取入缓存，用户请求优先命中缓存，避免逐次实时打 Polymarket 双 API。 |
| 分层 TTL | 元数据/列表 TTL 较长（分钟级），价格/赔率 TTL 较短；结果一律带数据快照时间返回。具体值由技术方案确定，兼顾时效与限流。 |
| 拉取失败 | 优先返回缓存快照并标注时间；无缓存时返回错误态供前端重试。 |
| Mock 数据 | 仅用于本地开发 / CI，不进入生产数据路径。 |

## 5. 合规与只读约束

- 全流程**只读**：仅拉取公开市场数据用于分析，无下单、无钱包连接、无资金操作。
- 结果为「市场偏差观察」，不构成投资建议，卡片与页面均标注数据来源与快照时间。
- 需遵守 Polymarket API 的速率限制与使用条款，通过缓存与合理拉取频率控制请求量。
